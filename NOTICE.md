# Third-party task data

Some tasks in `tasks/` come from public benchmarks and keep their upstream
licenses. The prompts, task wrappers and scripts written for this repository are
under its [Apache License 2.0](LICENSE). License texts are in this folder.

| Tasks | Source | License | Text |
|---|---|---|---|
| `poly-*` | [Exercism](https://exercism.org) exercises (Python, Go and Rust tracks), as selected by [Aider's polyglot benchmark](https://github.com/Aider-AI/polyglot-benchmark) | MIT | `EXERCISM-LICENSE` |
| `swe-*` | [SWE-bench](https://github.com/SWE-bench/SWE-bench) Lite and Verified | MIT | `SWE-bench-LICENSE` |
| `humaneval-*` | [HumanEval](https://github.com/openai/human-eval), with [EvalPlus](https://github.com/evalplus/evalplus) tests | MIT; Apache-2.0 | `HUMANEVAL-LICENSE`, `APACHE-2.0-LICENSE` |
| `mbpp-*` | [MBPP](https://github.com/google-research/google-research/tree/master/mbpp), with [EvalPlus](https://github.com/evalplus/evalplus) tests | Apache-2.0 | `APACHE-2.0-LICENSE` |
| `ds1000-*` | [DS-1000](https://github.com/xlang-ai/DS-1000) | CC BY-SA 4.0 | `DS1000-LICENSE` |
| `finqa-*` | [FinQA](https://github.com/czyssrs/FinQA) | MIT | `FINQA-LICENSE` |

**SWE-bench task content.** Problem statements are GitHub issues, and test
patches come from the upstream projects under their own licenses: pytest (MIT),
requests (Apache-2.0), Flask (BSD-3-Clause) and pylint (GPL-2.0-or-later). The
pylint tasks (`swe-pylint-dev__*`) and the result patches made against pylint
(`results/**/*pylint*`) stay under GPL-2.0-or-later (`GPL-2.0-LICENSE`).
Repository checkouts aren't stored here.

**Copyleft.** Two sets carry share-alike terms: DS-1000 (CC BY-SA 4.0) and the
pylint material (GPL-2.0-or-later). Both are benchmark data only; nothing from
them is part of the `chanto` program.
