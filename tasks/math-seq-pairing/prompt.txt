We store variable-length lists of non-negative integers under a single integer key, and the sampler picks random keys and decodes them, so every non-negative integer has to be a valid key. Please implement `encode(lst) -> int` and `decode(n) -> list` in listkey.py as an exact bijection between all finite lists of non-negative ints (including the empty list) and all non-negative ints: decode(encode(x)) == x for every list, and encode(decode(n)) == n for every n >= 0. Lists in production have up to 200 elements with values up to about 10**30, and both directions need to be fast (milliseconds), so keys can't blow up in size. test_listkey.py has the basics.
