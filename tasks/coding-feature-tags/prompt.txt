- `notes tag ID TAG [TAG...]` adds tags to an existing note (same normalization/validation; already-present tags are ignored) and `notes untag ID TAG [TAG...]` removes them (tags it doesn't have are ignored). Unknown IDs behave like `show` does today (exit 1, "no such note").
- My existing notes.json files have no tags and must keep loading. When the app saves, write `"version": 2` and give every note a `"tags"` list.

`main()` in notes/cli.py should keep returning the exit code. Keep the existing tests passing and add tests for the new behaviour.
