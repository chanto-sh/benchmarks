I'm balancing the end of a board game. A token starts on square 0 and the goal is square n. Each turn you roll a fair k-sided die (faces 1..k) and move forward. You must land on n exactly: if a roll would take you past n, you bounce back by the excess (from square n-1 a roll of 3 puts you on n-2). The game ends the moment you land on n.

Please implement `expected_turns(n, k)` in game.py: the exact expected number of turns from square 0 to finish, as a fractions.Fraction (we compare designs exactly, so no floats). It needs to work for any 1 <= k <= n <= 60. There's a small test file to start from.
